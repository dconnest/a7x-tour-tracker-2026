# A7X Tour Tracker 2026 — Next.js Version

## Deploy with GitHub + Vercel
1. Create a new GitHub repository or replace the files in your existing repository.
2. Upload every file and folder from this project.
3. In Vercel, import the repository.
4. Framework preset: **Next.js**.
5. Click **Deploy**.

Future show updates can be made in `data/tour.js`. Commit the change to GitHub and Vercel will redeploy automatically.
