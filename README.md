# A7X Tour Tracker 2026

Static fan-site prototype for the 2026 North American tour.

## Publish with GitHub and Vercel

1. Create a new GitHub repository named `a7x-tour-tracker-2026`.
2. Upload `index.html`, `README.md`, and `vercel.json` from this package.
3. In Vercel, choose **Add New → Project**.
4. Import the GitHub repository.
5. Leave the framework preset as **Other**.
6. No build command or output directory is required.
7. Click **Deploy**.

Every future GitHub update will trigger an automatic Vercel deployment.
